## PARTE III · Guía Práctica: Cómo Usar SonarQube y Medir Duplicación 100 % Gratis para Siempre

Si la prueba gratuita de 14 días para repositorios privados en **SonarQube Cloud (SonarCloud)** finalizó, existen **3 formas 100 % gratuitas e ilimitadas** de ejecutar el análisis estático completo (incluyendo el porcentaje de duplicación de código de la característica 7 de Mantenibilidad):

### Opción A: Cambiar los Repositorios a Públicos en SonarQube Cloud (100 % Gratis para Siempre en la Nube)
- **¿Cómo funciona?** SonarQube Cloud (`sonarcloud.io`) es **100 % gratuito para siempre y sin límite de líneas de código ni de escaneos** para todos los proyectos **Públicos (Open Source)** en GitHub o Azure DevOps.
- **Pasos:**
  1. En la configuración del repositorio (GitHub / Azure DevOps), cambiar la visibilidad de *Private* a *Public* (verificando primero que los archivos `.env` estén en `.gitignore`, como ya lo están en nuestros 3 repositorios).
  2. En **SonarQube Cloud** $\rightarrow$ *Administration* $\rightarrow$ *Update Key / Visibility*, cambiar el proyecto a **Public**.
  3. El *Quality Gate*, las gráficas de Mantenibilidad, Fiabilidad, Seguridad y Duplicación quedan activos gratuitamente de forma permanente.

### Opción B: SonarQube Community Edition en Docker Local (100 % Gratis para Proyectos Privados)
- **¿Cómo funciona?** Igual que se levanta Jenkins en Docker local, puedes levantar el servidor oficial **SonarQube Community Edition** en tu computador con un solo comando:
  ```bash
  docker run -d --name sonarqube -p 9000:9000 sonarqube:community
  ```
- Abres `http://localhost:9000` (usuario `admin`, clave `admin`) y escaneas cualquiera de los 3 repositorios con `npx sonar-scanner`, obteniendo exactamente la misma interfaz web de SonarQube sin pagar licencia ni depender de pruebas gratuitas de 14 días.

### Opción C: Ejecución Directa por Consola sin Docker (ESLint + TypeScript + `flutter analyze` + `jscpd`)
Para demostrar en vivo en la terminal el análisis estático y el porcentaje de duplicación sin levantar contenedores:
